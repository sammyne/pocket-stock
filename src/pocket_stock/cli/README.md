# CLI 命令行工具

极简的股票行情查询命令行工具，支持快速查询指定股票的实时行情信息。

## 功能特性

- 支持上海（sh）和深圳（sz）市场股票查询
- 异步网络请求，高效获取实时数据
- 美观的表格格式化输出
- 完善的错误处理机制
- 可配置请求超时时间

## 安装

```bash
# 使用 uv 安装
uv pip install -e .
```

## 使用方法

### 基本用法

```bash
# 查询浦发银行（上海市场）
uv run src/pocket_stock/cli/main.py sh600000

# 查询平安银行（深圳市场）
uv run src/pocket_stock/cli/main.py sz000001
```

### 设置超时时间

```bash
# 设置超时时间为 5 秒
uv run src/pocket_stock/cli/main.py -t 5 sh600000

# 设置超时时间为 15 秒
uv run src/pocket_stock/cli/main.py --timeout 15 sz000001
```

## 股票代码格式

股票代码由两部分组成：
- 市场代码（2位）：`sh`（上海）或 `sz`（深圳）
- 股票编号（6位）：数字

示例：
- 上海市场：`sh600000`、`sh600036`
- 深圳市场：`sz000001`、`sz000002`

## 退出码

| 退出码 | 说明 |
|--------|------|
| 0 | 成功 |
| 1 | 参数错误或股票代码格式无效 |
| 2 | 网络连接失败 |
| 3 | 数据服务异常 |
| 4 | 数据解析失败 |
| 5 | 未知错误 |
| 130 | 用户取消操作（Ctrl+C） |

## 命令行参数

| 参数 | 说明 |
|------|------|
| `stock_code` | 股票代码（必填） |
| `-t, --timeout` | 请求超时时间，单位秒（默认：10） |
| `-h, --help` | 显示帮助信息 |
| `--version` | 显示版本信息 |

## 依赖项

- Python >= 3.13
- aiohttp >= 3.9.0
- pydantic >= 2.0.0

## 注意事项

1. 本工具使用腾讯财经 API 获取实时行情数据
2. 行情数据仅供参考，不作为投资建议
3. 网络连接失败时，请检查网络设置或稍后重试
4. 超时时间建议设置为 5-15 秒

## 错误处理示例

### 股票代码格式错误

```bash
$ uv run src/pocket_stock/cli/main.py abc123
错误: 股票代码格式无效
  股票代码: abc123
  提示: 格式应为 sh 或 sz 开头，后跟 6 位数字，如 sh600000
```

### 网络连接失败

```bash
$ uv run src/pocket_stock/cli/main.py sh600000
错误: 网络连接失败
  股票代码: sh600000
  原因: 网络请求失败: [Errno 8] nodename nor servname provided
```
